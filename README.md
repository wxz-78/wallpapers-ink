# 🟨 Wallpapers - Ink

Colección de wallpapers en alta resolución para móvil y escritorio. Este repositorio está diseñado principalmente para el entorno de escritorio Linux, pero las imágenes pueden ser utilizadas en cualquier sistema.

Más que una simple colección de imágenes, este repositorio es una exploración visual de la condición humana. Cada wallpaper está diseñado para evocar emociones, reflejar críticas sociales y acompañar la estética oscura, melancólica y reflexiva del ecosistema **Ink**. 

> *"Prefiero sentir dolor a no sentir nada..."*

## ⚠️ Advertencia de Contenido (Content Warning)
Las imágenes en este repositorio abordan temáticas sensibles como la presión social, el agotamiento (burnout), el abandono parental, la soledad y la salud mental. La intención es puramente artística y crítica.
